# Vasista Avinash Behara — DevOps / Cloud Engineer

Personal portfolio site powered by Jekyll with the Minimal Mistakes theme, ready for GitHub Pages.

## Run locally
1. Install Ruby/bundler.
2. Install deps: `bundle install`
3. Serve with live reload: `bundle exec jekyll serve`
4. Open http://localhost:4000

## GitHub Pages deployment
- GitHub Pages builds from the `github-pages` gem and `remote_theme: mmistakes/minimal-mistakes`.
- Push changes to the `main` branch of `vasistabehara.github.io`; Pages will auto-build.

## Customize
- Edit site metadata in `_config.yml` (title, description, social links, navigation).
- Update content in `index.md` and `_pages/*.md`.
- Add images to `assets/images/`.
- Replace `assets/vasista-avinash-behara-resume.pdf` with your latest resume to update the download link.
